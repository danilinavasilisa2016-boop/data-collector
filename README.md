# Data Collector

Многомодульное приложение на Python с использованием PyQt5 для получения,
отображения и хранения данных о температуре, влажности и освещённости.
Результаты сохраняются в файл формата CSV.

## Возможности

- Главное окно с переходом к таблице данных
- Таблица с тремя столбцами: температура, влажность, освещение
- Кнопка «Считать данные» — добавление новой строки с полученными значениями
- Кнопка «Сохранить» — запись всех строк в файл `data.csv`
- Кнопка «Очистить» — удаление всех строк из таблицы
- Возможность подключения реальных данных от Arduino через последовательный порт (pyserial)

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Запуск программы, создание QApplication и главного окна |
| `main_window.py` | Главное окно, кнопки перехода к таблице и выхода |
| `table_window.py` | Окно с таблицей, кнопки «Считать данные», «Сохранить», «Очистить» |
| `data_reader.py` | Получение данных (тестовая строка, в будущем — Arduino) |
| `ui_main_window.py` | Сгенерированный интерфейс главного окна из Qt Designer |
| `ui_table_window.py` | Сгенерированный интерфейс окна таблицы из Qt Designer |
| `main_window.ui` | Интерфейс главного окна (Qt Designer) |
| `table_window.ui` | Интерфейс окна таблицы (Qt Designer) |
| `data.csv` | Файл с сохранёнными результатами |
| `dist/DataCollector.exe` | Собранное исполняемое приложение |

## Требования

- PyQt5
